# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of EFF seriously. If you discover a vulnerability or security risk:

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email details of the vulnerability to `info@eff-egypt.com` or contact the repository owner privately through GitHub Security Advisories.
3. Include detailed steps to reproduce the issue, sample input payloads, and affected versions.
4. You will receive an acknowledgment within 48 hours, followed by updates on the assessment and fix timeline.
